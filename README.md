# 星之祈祷 · Windows Releases

这里只发布「星之祈祷」的 Windows 安装包、便携包和校验文件。

源码仓库为私有仓库，不在此仓库中提供源代码。

## 下载

- 安装包：`StarPrayer-Setup-0.3.3.exe`
- 便携版：`StarPrayer-Portable-0.3.3.zip`
- 校验文件：`SHA256SUMS-0.3.3.txt`

请从本仓库的 **Releases** 页面下载对应版本。

## 安装说明

1. 下载 `StarPrayer-Setup-0.3.3.exe`。
2. 运行安装程序，可自行选择安装目录。
3. 安装程序默认优先复用已有的「星之祈祷」安装路径。
4. 如果 Windows SmartScreen 提示未知发布者，这是未做代码签名时的正常提示。
