# 星之祈祷 · Windows Releases

「星之祈祷」的 Windows 安装包、便携包和校验文件。

## 下载

- 安装包：`StarPrayer-Setup-0.3.3.exe`
- 便携版：`StarPrayer-Portable-0.3.3.zip`
- 校验文件：`SHA256SUMS-0.3.3.txt`

请从本仓库的 **Releases** 页面下载对应版本。

## 观星 APK（用于获取登录凭证）

Release 中附带公开版观星 APK：

```text
StargazerPublic-1.16.apk
```

用途：在 Android 设备上读取当前游戏的登录凭证（`uuid` / `aptkn`），再把凭证
用于 PC 端登录。它不是游戏本体，不能替代《Pokémon Sleep》。

> **安全提示：导出的凭证包含账号 `uuid` 和 application token。拿到该文件的人
> 可以直接登录对应账号。不要上传、转发或公开分享凭证；使用后及时删除导出文件。**

当前适配游戏版本和具体操作以 APK 内说明为准。

## 安装说明

1. 下载 `StarPrayer-Setup-0.3.3.exe`。
2. 运行安装程序，可自行选择安装目录。
3. 安装程序默认优先复用已有的「星之祈祷」安装路径。
4. 如果 Windows SmartScreen 提示未知发布者，这是未做代码签名时的正常提示。
